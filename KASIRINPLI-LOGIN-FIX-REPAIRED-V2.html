👥 Kasir Owner

Owner dapat menambahkan kasir tanpa batas. Setiap kasir otomatis hanya terhubung ke Owner yang sedang login.

Login lebih gampang
  1. Admin membagikan 1 link aplikasi kepada Owner/Kasir.
  2. Owner membuka link di perangkat tujuan.
  3. Link disimpan di perangkat tersebut, jadi berikutnya cukup tekan Buka Kasir.
  4. Login tetap memakai akun yang diberikan Admin; jangan membagikan PIN.
Catatan: HTML lokal tidak bisa menyinkronkan transaksi antar-HP. Untuk transaksi yang sama secara real-time di semua perangkat, aplikasi perlu server/cloud dengan database bersama.
